# noteからSalfinへ下書き転記

Computer Useでログイン済みブラウザを操作し、note下書きをSalfin下書きへ転記する。APIや非公式エンドポイントは使用しない。

## 手順

1. note編集URLとSalfinへの転記許可を確認する。公開は禁止する。
2. note編集画面からタイトル、本文、アイキャッチ画像、見出し、箇条書き、リンクを確認する。
3. アイキャッチ画像を右クリックし、ローカルへ保存する。
4. Salfinの新規記事編集画面を開く。
5. タイトルを入力する。
6. 本文が空の状態で本文先頭へカーソルを置き、アイキャッチ画像を最初に挿入する。Salfinは現在のカーソル位置へ画像を挿入するため、本文転記後にアップロードしない。
7. note本文だけを全選択してリッチテキストとしてコピーし、Salfinの画像直後へ貼り付ける。
8. 見出し、箇条書き、強調、Qiitaなどのリンクが保持されているか確認する。リンクカードは通常リンクへ変換される場合がある。
9. 「下書き保存」を実行し、`https://salfin.jp/editor/<id>` の編集URLになったことを確認する。
10. 「記事を公開」は押さない。

## 検証

- タイトルが一致する。
- アイキャッチ画像が本文先頭にある。
- 本文が欠落していない。
- 見出しと箇条書きが維持されている。
- 外部リンクが正しいURLを指している。
- Salfinの記事が下書きであり、公開されていない。

## エラー処理

- 画像が本文末尾へ入った場合は保存せず停止する。削除や取り消しの直前にユーザー確認を取る。
- ログイン切れ、CAPTCHA、権限不足があれば停止してユーザーへ操作を依頼する。
- 転記先に必須項目や公開に関係する選択肢が追加されていたら、下書き保存前に確認する。
